# LanDrop — карточка магазина (русский)

Целевая площадка — Google Play; те же поля подходят для RuStore и F-Droid.
Лимиты указаны для Google Play.

## Название (до 30 символов)

LanDrop — файлы по Wi-Fi

## Краткое описание (до 80 символов)

Файлы с компьютера на телефон по Wi-Fi — без кабеля, облака и аккаунтов.

## Полное описание (до 4000 символов)

LanDrop превращает Android-телефон в общую папку Wi-Fi сети. Приложение поднимает HTTP-сервер, и файлы с компьютера загружаются через обычный браузер — без кабеля, облака, аккаунтов и интернета.

Откройте адрес вида http://192.168.1.42:8080 на ноутбуке, перетащите файлы на страницу — и они окажутся на телефоне. Там же можно посмотреть фото и видео из медиатеки, скачать их обратно на компьютер или удалить ненужное.

**Как это работает**

1. Подключите компьютер и телефон к одной Wi-Fi сети.
2. Включите сервер в LanDrop.
3. Откройте адрес с главного экрана в браузере.
4. Перетащите файлы на страницу загрузки.

**Что умеет**

• Передача с ПК через браузер: drag-and-drop или выбор файлов, без установки клиента.
• До трёх одновременных передач, скорость, оставшееся время и отмена одного файла или всей очереди.
• Превью картинок в очереди и списке принятых файлов, кадры видео в галерее.
• Галерея фото и видео телефона: вкладки источников, ленивые миниатюры, поиск, просмотр с листанием свайпом, стрелками и с клавиатуры.
• Скачивание оригинала и поддержка Range для видео.
• Светлая и тёмная темы на каждой странице; выбор запоминается, а до первого выбора используется системная тема.
• Список принятых файлов в приложении: поиск, открытие во внешнем приложении, удаление.
• HTTP API и простой бинарный протокол для скриптов и автоматизации.

**Без облака и подписок**

Файлы не покидают вашу локальную сеть: LanDrop не отправляет данные в интернет, не использует сторонние SDK и не требует регистрации. Сервер работает, пока включён, и доступен только устройствам в той же Wi-Fi сети.

**Требования**

• Android 7.0 и новее.
• Телефон и компьютер в одной Wi-Fi сети.
• Для галереи на Android 13+ нужно разрешение на фото и видео; без него доступны остальные функции и список принятых файлов.

**Полезно знать**

• Если компьютер не открывает адрес, проверьте, что сеть не разделяет клиентов (guest Wi-Fi) и брандмауэр не блокирует порт 8080.
• Сервер не имеет авторизации: не публикуйте его в интернете и используйте в доверенной сети.
• Аудиодорожки некоторых видео (DTS/AC3 в MKV) браузер не воспроизводит; файл можно скачать и открыть в плеере.
